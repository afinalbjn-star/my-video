## 🚀 Cara Menggunakan Update Baru:

### **Auto-Open Browser (Otomatis)**
1. Double-click shortcut desktop: `Chatbot AI`
2. Server akan berjalan otomatis
3. **Browser akan terbuka otomatis** di `http://127.0.0.1:8000`
4. Chatbot siap digunakan!

### **Voice Input (Perintah Suara)**
1. Klik tombol 🎤 di pojok kanan atas
2. Akan muncul modal voice input
3. Klik **Start** untuk mulai merekam
4. Bicarakan perintah Anda (contoh: "Jelaskan tentang AI")
5. Klik **Stop** untuk berhenti merekam
6. Transcript akan muncul di modal
7. Klik **Gunakan** untuk mengirim ke chatbot
8. Atau edit transcript dulu jika perlu

## 🎯 Cara Menggunakan Voice Command:

### **Contoh Perintah Suara:**
- "Halo, apa kabar?"
- "Jelaskan tentang teknologi blockchain"
- "Buat contoh code Python untuk sorting"
- "Analisis tren AI tahun 2024"
- "Tulis artikel tentang manfaat olahraga"

### **Tips Voice Input:**
1. **Bicara dengan jelas** agar transcription akurat
2. **Gunakan bahasa Indonesia** (default setting)
3. **Lingkungan yang tenang** untuk hasil lebih baik
4. **Tunggu sampai transcript selesai** sebelum klik "Gunakan"

## 🔧 Konfigurasi Bahasa:

### **Mengganti Bahasa Voice Recognition:**
Edit file `templates/index.html`, cari baris ini:
```javascript
recognition.lang = 'id-ID'; // Bahasa Indonesia
```

Ganti dengan:
- `'en-US'` untuk English
- `'ja-JP'` untuk Japanese
- `'ko-KR'` untuk Korean
- `'zh-CN'` untuk Chinese
- dll sesuai kode bahasa yang diinginkan
