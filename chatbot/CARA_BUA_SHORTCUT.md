# 🎯 Cara Membuat Shortcut Chatbot AI di Desktop

## 🚀 Cara Paling Mudah (Manual)

### **Langkah 1: Buka Folder Chatbot**
1. Buka File Explorer
2. Navigasi ke: `C:\Users\afina\my-video\chatbot`

### **Langkah 2: Klik Kanan File Script**
1. Cari file: `start-advanced.bat`
2. Klik kanan pada file tersebut
3. Pilih: **Send to** → **Desktop (create shortcut)**

### **Langkah 3: Selesai!**
Sekarang ada shortcut "start-advanced.bat - Shortcut" di desktop Anda

## 🎨 Cara Mengubah Nama Shortcut (Opsional)

### **Langkah 1: Klik Kanan Shortcut**
1. Pergi ke Desktop
2. Klik kanan shortcut yang baru dibuat
3. Pilih **Rename**

### **Langkah 2: Beri Nama Baru**
1. Ketik nama baru: `Chatbot AI`
2. Tekan Enter

## 🔄 Cara Menggunakan Shortcut

### **Setiap Mau Membuka Chatbot:**
1. Double-click shortcut di desktop
2. Tunggu server berjalan (muncul command prompt)
3. Buka browser: `http://127.0.0.1:8000`

### **Setelah Selesai:**
1. Pergi ke command prompt yang terbuka
2. Tekan `Ctrl + C` untuk menghentikan server
3. Tutup command prompt

## 📱 Cara Menambah Shortcut ke Taskbar

### **Langkah 1: Drag ke Taskbar**
1. Drag shortcut desktop ke taskbar
2. Lepaskan (drop) di taskbar

### **Langkah 2: Selesai!**
Sekarang ada icon di taskbar untuk akses cepat

## 💡 Alternative: Buka Start Menu

### **Langkah 1: Pin ke Start Menu**
1. Klik kanan `start-advanced.bat`
2. Pilih **Pin to Start**

### **Langkah 2: Akses dari Start Menu**
1. Tekan tombol Windows
2. Cari "Chatbot AI" atau "start-advanced"
3. Klik untuk membuka

## ⚠️ Jika "Send to" Tidak Tersedia

### **Langkah 1: Copy File**
1. Klik kanan `start-advanced.bat`
2. Pilih **Copy**

### **Langkah 2: Paste ke Desktop**
1. Pergi ke Desktop
2. Klik kanan di area kosong
3. Pilih **Paste shortcut**

### **Langkah 3: Rename**
1. Klik kanan shortcut yang baru
2. Pilih **Rename**
3. Beri nama: `Chatbot AI`

## 🎯 Cara Paling Praktis (Recommended)

### **Option 1: Shortcut di Desktop**
- Mudah: Double-click untuk buka
- Kelemahan: Desktop jadi penuh jika banyak shortcut

### **Option 2: Shortcut di Taskbar** ⭐
- Paling cepat: Satu klik dari taskbar
- Desktop tetap bersih
- Recommended untuk penggunaan harian

### **Option 3: Pin ke Start Menu**
- Terorganisir di Start Menu
- Bagus jika punya banyak aplikasi

## 📝 Ringkasan Langkah Cepat:

1. Buka folder: `C:\Users\afina\my-video\chatbot`
2. Klik kanan `start-advanced.bat`
3. Pilih **Send to** → **Desktop (create shortcut)**
4. Selesai! ✅

**Setelah itu:** Double-click shortcut di desktop untuk membuka chatbot!
